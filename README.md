# samudra-ledger

The public, append-only record of Samudra's frozen prediction files.

Each entry is a book of predictions frozen on a stated date and hashed. The
hash is timestamped and archived immediately. The file itself publishes when
the window closes and the county's deeds have graded it.

**Read [LEDGER.md](LEDGER.md) for the protocol and the two-phase promise.**
